Implement the work described by the user in the PRD or issues.

Run typechecking (`pnpm run build`) and lint regularly, and the validation scripts once at the end.

Once done, use /review to review the work.

Do NOT commit. Only the user makes commits — when the work is ready, say "listo para commitear" and let the user commit.
