# 01 — Terminar Magic Wonderful (MW)

- **Prioridad:** Alta
- **Estado:** pendiente

## Contexto

`src/data/MWCases.ts` tiene **41 casos** pero sospechas de que el set no está
terminado ni verificado:

- El catálogo (`src/data/algorithmCatalog.ts`) reporta **32** casos para MW,
  desincronizado con los 41 del dataset.
- Los casos parecen genéricos ("Basic insertion", "Double trigger", "Sune
  variation"…). Hay que confirmar que son casos reales de Magic Wonderful con
  scrambles correctos.
- MW es "lo siguiente después de WV — todo es con mirror" (regla de dominio).

## Qué hay que hacer

- [ ] Auditar los 41 casos actuales: IDs, nombre real del caso, `algorithm`
      correcto, `scramble` correcto (o regla: usar `invert(algorithm)`).
- [ ] Completar casos faltantes hasta el set completo de MW.
- [ ] Validar con un script estilo `verifyWVCases.ts` (`pnpm run verify-wv`):
      el scramble genera el caso y el algoritmo lo resuelve.
- [ ] Sincronizar `count` del catálogo con el dataset real.

## Cómo / Diseño

- Referencia para el conteo real de MW: verificar contra fuentes del set
  (alg.cubing.net, guides). Confirmar si son 41 o otro número.
- Reusar las convenciones de `WVCases.ts` (ids `mw-01`…, `scramble: ""` si se
  usa `invert(algorithm)` en runtime).

## Criterios de aceptación

- [ ] Todos los casos: algoritmo parsea y resuelve el caso; scramble correcto.
- [ ] Conteo del catálogo == dataset == documentado.
- [ ] Un script de verificación pasa para todos los casos MW.
